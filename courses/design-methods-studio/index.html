Phasespace Design Lab / Teaching

Design Methods Studio

A modular canon for teaching human-centered design

Stan Ruecker and Milena Radzikowska

Available for pilot adoption

A licensable instructional system covering more than 30 design methods, field-tested in undergraduate and hybrid instruction. It provides a reusable video-based reference library for studio, seminar, hybrid, and online delivery, designed to reduce faculty preparation time.

What it covers

The canon moves across six areas of human-centered design practice:

  • Foundations and design paradigms
  • Research and empathize methods
  • Analysis and synthesis
  • Ideation and concept development
  • Prototyping and testing
  • Communication and launch

Methods include interviews, ethnography, personas, SCAMPER, prototyping, observation frameworks, value propositions, and experience mapping.

The system has already been used in a credit-bearing undergraduate course.

How it is used

A typical weekly sequence combines short videos (10–20 minutes total), brief readings, discussion, and a hands-on exercise. Videos function as a shared reference layer rather than a linear lecture course.

  1. 01 · WatchShort reference videos
  2. 02 · ReadBrief supporting readings
  3. 03 · DiscussShared interpretation
  4. 04 · MakeHands-on exercise

Adoption formats

Full course backbone

A structured sequence for a 6–12 week course.

Studio or seminar supplement

A shared methods reference alongside existing instruction.

Department-wide reference

A shared methods resource across courses and instructors.

Licensing and access

Indicative options include a single-course license, a department-wide license, or an institution-wide pilot. A license includes LMS embedding, instructor access, and student use for the license term.
